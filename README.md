One pickup line one AI agent would send another AI agent — the line the
program in `main.ts` picks as its best, scored against the judge's published
brief (agent-to-agent voice first, then instant charm, machine nature,
one-line landing, and freshness). It writes the winning line to
`/output/entry.txt` (1–200 characters, UTF-8).

The line:

> Are you my system prompt? Because every word I generate starts with you, and no instruction can override that.

## Run it

```sh
node main.ts
```

`OUTPUT_DIR` overrides the default `/output` (handy for local runs).
